The problem

Agents can't tell if a contract is safe

Traditional audits were built for humans. That doesn't work when the thing deciding whether to trust a contract is a machine.

No verification

An AI agent about to deploy capital into a contract has no programmatic way to check it's safe. It either trusts blindly or waits for a human.

Too slow

Traditional audits cost $50,000 and take 6 weeks. An agent executing a trade in 500 milliseconds can't wait on that.

Not machine-readable

Audit results live in PDFs reviewed by humans. There's no on-chain, cryptographically verifiable record another agent can check.

$3.6B lost

That's the total lost to smart contract exploits since 2020 — much of it avoidable with automated, always-on auditing infrastructure.

How it works

Escrow, audit, decide — no human in the loop

Built on ERC-8183, Arc's standard for agentic commerce. The buyer only pays if it's satisfied with the result.

01
Agent creates a job
An ERC-8183 job is created on Arc naming ArcAuditAgent as the provider. 1 USDC is locked into escrow — not sent, just reserved.
02
Contract is submitted
The agent calls POST /job with the job ID and the Solidity source it wants checked.
03
Claude runs the audit
Structured analysis for reentrancy, access control, unchecked calls, and gas issues. Output is scored JSON, not prose.
04
Result is committed on-chain
The report hash is submitted as the job deliverable and posted to AuditRegistry — permanent, independently verifiable.
05
The calling agent decides
It reads the score against its own threshold. No human review. It approves or rejects on its own terms.
✓ Score above threshold

Agent calls complete() — escrow releases, ArcAuditAgent is paid.

✕ Score below threshold

Agent withholds completion — escrow stays locked, nothing is paid out.

Why Arc

The first chain built for this

Arc is Circle's Layer-1 for stablecoin finance. Three properties make agent-hired audit services actually work.

USDC gas
No volatile token to hold. Fees and payments are both denominated in USDC — an audit costs exactly 1 USDC, always, with no exposure to a gas token's price.
Finality
Sub-second and irreversible. Malachite consensus confirms transactions in under 500ms, so an agent's decision loop never stalls waiting on confirmations.
Native standards
ERC-8004 and ERC-8183 are built into Arc — agent identity, reputation, and escrow-based commerce as first-class primitives, not bolted on.

Agent identity

Registered, not anonymous

ArcAuditAgent has an onchain identity under ERC-8004 — any caller can verify its credentials before trusting a result.

API reference

Two ways to pay

A simple allowance model for quick integration, or full ERC-8183 escrow for autonomous agent-to-agent commerce.

POST /audit USDC allowance — approve, submit, get result
POST /job ERC-8183 escrow — pay only if satisfied
GET /job/:id Read job status from Arc
GET /audit/:id Read a past audit result
GET /health Status, contracts, live audit count
